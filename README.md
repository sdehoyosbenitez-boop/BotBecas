# Scholarship Bot

Bot en Python para buscar becas para colombianos (16+) y enviar alertas
por Telegram.

## Características

-   Búsqueda automática de becas de pregrado y cursos cortos.
-   Filtros por país, idioma y cobertura.
-   Alertas por Telegram.
-   Arquitectura modular.
